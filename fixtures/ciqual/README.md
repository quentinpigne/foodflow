# Extrait de la table Ciqual

Quelques aliments de la table Ciqual 2020 (ANSES), au format XML d'origine (Windows-1252), pour les tests du
lecteur (`crates/server/src/readers/ciqual.rs`) et de l'import.

Source : ANSES, Table de composition nutritionnelle des aliments Ciqual 2020, https://ciqual.anses.fr,
réutilisée sous licence ouverte Etalab 2.0.

`noms-2020.json` : codes et noms de tous les aliments et familles de la table, tels qu'importés par Foodflow,
pour mesurer le rattachement des ingrédients importés (`crates/server/src/services/matching_tests.rs`).
